- `spotipy_scripts`: Spotify automation workspace with playlist tools, FastAPI backend, and web UI.
- `Delivery-Tracker`: Simple delivery tracking web app deployed on GitHub Pages.
- `mayman20.github.io`: Personal site and portfolio experiments.
- `surf-cam.github.io`: Static surf cam site experiment.
- `titanic_dataset`: Early data exploration project using the Titanic dataset.

## Readme Direction

The profile README should do three things:

1. Tell a coherent story about what you build now
2. Point reviewers to the strongest repos first
3. Make older or smaller repos feel intentional instead of random
